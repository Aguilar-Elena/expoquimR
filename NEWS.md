# expoquimR 0.2.0

* Added `une689_probability_data()` and `une689_probability_plot()` for
  graphical examination of exposure distributions on probability paper.
* Integrated probability plots into the UNE-EN 689 Shiny application and
  the HTML report template.
* Expanded tests and documentation, and added a related research citation.
* Corrected package author metadata to Guillén Riquelme.

The new graphical output is an aid to professional interpretation, not an
automated determination of SEG validity.

## Software peer-review preparation

* Preparation of the package for external software peer review.
* Added contribution guidelines and a code of conduct.
* Expanded quality-assurance and reproducibility infrastructure.
* Ongoing documentation of reference-case verification against previously
  completed occupational hygiene assessments.
* Review of methodological references and package documentation.

# expoquimR 0.1.0

* Initial CRAN release.
* Added implementations of COSHH Essentials, the INRS simplified chemical
  risk assessment method, and UNE-EN 689 occupational exposure assessment.
* Added programmatic R interfaces, Excel-based workflows, and optional
  Shiny applications.
* Added English and Spanish output.
