# Changelog

## expoquimR (development version)

### Software peer-review preparation

- Preparation of the package for external software peer review.
- Added contribution guidelines and a code of conduct.
- Expanded quality-assurance and reproducibility infrastructure.
- Ongoing documentation of reference-case verification against
  previously completed occupational hygiene assessments.
- Review of methodological references and package documentation.

## expoquimR 0.1.0

CRAN release: 2026-08-09

- Initial CRAN release.
- Added implementations of COSHH Essentials, the INRS simplified
  chemical risk assessment method, and UNE-EN 689 occupational exposure
  assessment.
- Added programmatic R interfaces, Excel-based workflows, and optional
  Shiny applications.
- Added English and Spanish output.
