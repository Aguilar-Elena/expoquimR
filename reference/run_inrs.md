# Launch the INRS method Shiny application

Launch the INRS method Shiny application

## Usage

``` r
run_inrs(...)
```

## Arguments

- ...:

  Additional arguments passed to
  [`shiny::runApp()`](https://rdrr.io/pkg/shiny/man/runApp.html) (e.g.
  `launch.browser`, `port`).

## Value

No return value, called for side effects. Launches a Shiny application
in the default browser.

## Examples

``` r
if (FALSE) { # interactive()
run_inrs()
}
```
