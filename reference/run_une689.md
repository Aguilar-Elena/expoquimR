# Launch the UNE-EN 689 Shiny application (preliminary, statistical and periodic assessment)

Launch the UNE-EN 689 Shiny application (preliminary, statistical and
periodic assessment)

## Usage

``` r
run_une689(...)
```

## Arguments

- ...:

  Additional arguments passed to
  [`shiny::runApp()`](https://rdrr.io/pkg/shiny/man/runApp.html) (e.g.
  `launch.browser`, `port`).

## Value

No return value, called for side effects. Launches a Shiny application
in the default browser.

## Examples

``` r
if (FALSE) { # interactive()
run_une689()
}
```
